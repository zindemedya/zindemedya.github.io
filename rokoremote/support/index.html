Support

1

Keep your phone and Roku on the same local network. A phone on 5 GHz and Roku on 2.4 GHz can work when the router allows communication. Guest networks and client isolation can block discovery.

2

If discovery fails, use Manual IP with the device's local IPv4 address. Manual IP cannot overcome network isolation.

3

Check the device is powered on and reachable. Where available, check Settings → System → Advanced system settings → Control by mobile apps. Software versions may limit remote control.

4

Volume, power, keyboard and app launching depend on device capabilities. If Wi-Fi changes, rediscover the device or reconnect.

5

Remove Ads is a one-time purchase. To restore it, use the same Google Play account. For further help use Zinde Medya's developer contact listed on Google Play.
